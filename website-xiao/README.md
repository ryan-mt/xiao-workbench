# Xiao Workbench website

Official introduction site for [Xiao Workbench](https://github.com/ryan-mt/xiao-workbench).

## Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS v4

## Develop

```powershell
npm install
npm run dev
```

## Check

```powershell
npm run lint
npm run typecheck
npm run build
```

## Content rules

Landing copy and screenshots are grounded in the Xiao product repository. Do not invent features, metrics, testimonials, or customer logos.
